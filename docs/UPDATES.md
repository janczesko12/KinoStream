# KinoStream app updates

KinoStream checks for updates when the Updates card in Settings is opened. The checker reads the `latest` GitHub Release, downloads `update.json`, and only offers an APK with a higher `versionCode` than the installed app.

The update manifest contains:
- `versionCode` and `versionName` from the APK build metadata;
- `apkUrl`, the stable APK download URL from the `latest` release;
- `sha256`, verified after downloading and before Android's installer is opened;
- `changelog`, a short description of the main-branch commit.

The GitHub Actions workflow builds/tests the app on every push to `main`. If the repository Actions secrets `SIGNING_KEYSTORE_BASE64`, `STORE_PASSWORD`, and `KEY_PASSWORD` are configured, it builds a release-signed APK and updates the `latest` GitHub Release with `app-release.apk` and `update.json`.

Keep the same signing keystore for every release. Android will reject an in-place update if the APK signature differs from the installed app. Build versions generated by CI increase the version code and version name for each workflow run.
